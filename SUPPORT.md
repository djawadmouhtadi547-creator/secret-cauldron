# Support

Prime Launcher is an independent pre-release project from Gmu Studios.

- **Bugs:** open a GitHub issue using the Bug report template after checking existing issues.
- **Feature ideas:** use the Feature request template.
- **Security vulnerabilities:** follow `SECURITY.md`; do not use a public issue.
- **Build failures:** include the workflow run link and sanitized error output, never secrets.

Before requesting support, include the Prime Launcher version, OS version, reproduction steps, and whether `npm run validate` passes. Redact usernames, personal file paths, account data, tokens, and private server addresses from logs.

There are no official social/support URLs configured in this source tree yet; avoid adding unverified links.
